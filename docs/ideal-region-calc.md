# Ideal Region — подбор регионов

## Приоритет шагов

1. **Step 1** — доминирующий критерий: **горы / водопады / озёра / города**  
   (вопрос шага называется «Какой пейзаж вам нравится», но в подборе используется именно выбранный вариант).
2. **Шаги 2–7** — уточнение среди регионов с одинаковым (или близким) баллом по step 1.
3. В ответ уходят **топ-3** региона.

## Алгоритм

1. Для каждой категории производителя (Швейцария / `manufacturer_id` из WP) читаем оценки.
2. Считаем:
   - `step1_score` — оценка выбранного критерия шага 1 (горы/водопады/озёра/города);
   - `rest_score` — среднее шагов 2–7;
   - `match_score` — взвешенный балл (~55% step1 + ~45% rest) для отображения.
3. Сортировка: `step1_score` ↓, затем `rest_score` ↓.
4. Выбор топ-3: сначала регионы с максимальным step1; если меньше трёх — расширяем на step1−1 и т.д.

## Ответ API

- `result.top_regions` / `matched_names` — два лучших региона  
- `result.ranking` = `step1_dominant`  
- в алерте WP: «главный приоритет — Горы» (или Водопады / Озёра / Города) + оценки
