# Ideal Region — подбор регионов



## Схема шагов (новая)



Источник: `config/ideal_region_category_fields.php`



1. **Сезон** — Когда вы планируете поездку? (1 ответ)

2. **Длительность** — Какова продолжительность вашего путешествия? (1)

3. **Группа** — Кто входит в состав вашей группы? (1)

4. **Транспорт** — Каким транспортом вы планируете передвигаться? (1)

5. **Природа** — Какая природа и атмосфера вас вдохновляют? (до 2)

6. **Занятия** — На каких занятиях вы хотите сделать главный акцент? (до 2)

7. **Бюджет** — Какой ценовой формат поездки вы рассматриваете? (1)

8. **Ограничения** — Есть ли у вас специфические пожелания или ограничения? (до 3; «Дополнительных пожеланий нет» — exclusive)



У категории в админке для каждого варианта: **input** (`stepN_key`) + **textarea** (`stepN_key_description`).



## Приоритет шагов



1. **Step 1** — доминирующий критерий (сейчас сезон).

2. **Шаги 2–8** — уточнение среди регионов с одинаковым (или близким) баллом по step 1.

3. В ответ уходят **топ-3** региона.



## Алгоритм



1. Для каждой категории производителя (Швейцария / `manufacturer_id` из WP) читаем оценки.

2. Считаем:

   - `step1_score` — оценка выбранного критерия шага 1;

   - `rest_score` — среднее шагов 2–8;

   - `match_score` — взвешенный балл (~55% step1 + ~45% rest) для отображения.

3. Сортировка: `step1_score` ↓, затем `rest_score` ↓.

4. Выбор топ-3: сначала регионы с максимальным step1; если меньше трёх — расширяем на step1−1 и т.д.



## Ответ API

- `result.top_regions` / `matched_names` — топ-3  
- `result.ranking` = `step1_dominant`  
- у каждого региона: `match_score` (0–100 → **% совпадения** на фронте), `description` / `description_html`  
- `step_slots` — схема слотов из конфига  

На WP карточка результата: 🥇/🥈/🥉 → **Совпадение: N%** → полное описание («Почему именно» + «Что включить»).
